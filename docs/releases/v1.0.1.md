# v1.0.1

## Summary

This release establishes a strict, reproducible quality baseline for the repository.

- All major lint/format/type checks are now mandatory.
- Local and CI quality gates are aligned.
- CI action dependencies were updated and pinned to latest stable versions used in this branch.
- Copilot instruction, agent, prompt, and skill files were added for project-specific workflows.

## Highlights

### 1. Mandatory Quality Gate System

Added a single canonical quality entrypoint and made it blocking both locally and in CI.

- New script: `scripts/quality_checks.sh`
- New local runner: `scripts/local/run_quality_local.ps1`
- Enforced checks:
  - `shfmt`
  - `shellcheck`
  - `ruff format --check`
  - `ruff check`
  - `mypy`
  - `yamllint`
  - `hadolint`
  - `markdownlint-cli2`
  - custom 140-char line-length checker for non-Markdown files

### 2. 140-Character Policy (Non-Markdown)

Added explicit line-length enforcement for non-Markdown source/config files.

- New checker: `scripts/check_line_length.py`
- Editor defaults: `.editorconfig`
- Markdown line-length is intentionally not enforced.

### 3. CI Hardening and Dependency Updates

CI workflow now blocks tests behind a quality gate and uses updated pinned action tags.

- Workflow updated: `.github/workflows/ci.yml`
- Quality job: `quality-gates`
- Tests depend on quality success.
- Coverage still enforced at 90% minimum.

Updated CI action tags in this release:

- `actions/checkout@v7.0.0`
- `docker/setup-buildx-action@v4.2.0`
- `docker/build-push-action@v7.3.0`
- `actions/upload-artifact@v7.0.1`
- `actions/download-artifact@v8.0.1`
- `marocchino/sticky-pull-request-comment@v3.0.5`

### 4. Docker Tooling Baseline

Expanded and pinned the test image toolchain for reproducible local and CI quality runs.

- Updated: `Dockerfile`
- Added/pinned lint tooling and dependencies used by quality checks.

### 5. Source Refactors for Lint Compliance

Refactored scripts and helpers to pass strict checks without suppression comments.

- Removed suppression from `bing_wallpaper.sh`
- Updated shell formatting in runtime and helper scripts
- Updated coverage utility Python scripts to typed, lint-clean structure

### 6. Copilot Project Customization

Added project-level Copilot artifacts for consistent agent behavior and maintainability.

- Added:
  - `.instructions.md`
  - `.prompt.md`
  - `AGENTS.md`
  - `.github/copilot-instructions.md`
  - `.github/instructions/*`
  - `.github/prompts/*`
  - `.github/agents/*`
  - `.github/skills/*`
