# v1.0.3

## Summary

This release adds SonarQube Cloud analysis to CI, updates every pinned dependency,
and cleans up the scripts to follow SonarQube's Bash, Dockerfile, and GitHub Actions
rules. Wallpaper, installer, and uninstaller behavior is unchanged for users.

- New `sonarqube` CI job scans the repository on SonarQube Cloud and uploads merged
  kcov coverage.
- Test-image tooling, pre-commit hooks, and GitHub Actions are on their latest releases.
- The shell scripts, Dockerfile, and workflows were refactored to follow SonarQube's
  quality rules.

## Highlights

### 1. SonarQube Cloud Integration

- `sonar-project.properties` configures project `ventura8_Raspberry-Pi-OS-Bing-Wallpaper-Auto-update`
  in organization `ventura8`. Product scripts, `scripts/`, the `Dockerfile`, and workflows
  are sources, and `tests/` is test code.
- New `scripts/cobertura_to_sonar.py` converts the merged kcov Cobertura report into
  SonarQube generic coverage (`coverage/sonar-coverage.xml`) with repo-relative paths.
- The `coverage-report` job produces that file and hands it to the new `sonarqube` job.
  The `sonarqube` job runs `SonarSource/sonarqube-scan-action` v8.2.2 with the
  `SONAR_TOKEN` repository secret and sets the project version from `VERSION`.
- The scan is skipped for pull requests from forks, which cannot read secrets.
- README shows the SonarQube quality gate badge.

### 3. SonarQube Rule Cleanup

- **Shell** (`bing_wallpaper.sh`, `install.sh`, `uninstall.sh`, test runners, mocks):
  - `[[ ]]` replaces `[ ]` in conditionals.
  - Functions end with an explicit `return`.
  - Positional parameters are copied into locals.
  - Error messages go to stderr.
- **Installer**: hour/minute validation now uses base-10 arithmetic (`10#`), so inputs
  with a leading zero such as `08` are still accepted.
- **Dockerfile**:
  - The `SHELL` is set with `pipefail`.
  - apt packages are sorted.
  - `npm install --ignore-scripts` is used.
  - Only the files the gates need are copied, instead of `COPY . .`.
  - The two `RUN` steps are merged into one.
  - Every `curl` download enforces HTTPS, including on redirects (`--proto '=https' --tlsv1.2`).
- **Coverage converter**: `scripts/cobertura_to_sonar.py` only reads and writes paths
  inside the project root (the working directory).
- **Workflows**:
  - Every action is pinned to a full commit SHA.
  - Permissions are least-privilege: read-only at the workflow level, with writes granted per job.
  - `$PWD` is quoted in `docker run` volume arguments.
- `scripts/quality_checks.sh` now also runs yamllint on `.github/workflows/release.yml`.
